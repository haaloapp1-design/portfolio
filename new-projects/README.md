# New projects inbox

To add a project to the website:

1. Make a folder here with the project's name, for example `new-projects/my-app/`.
2. Put anything you have inside it: a `notes.txt` with a few lines about the
   project (what it does, tech used, status, links) and screenshots if you have them.
3. Open this repo in Claude Code and type `/add-project`, or just say
   "add the new project".

Claude Code turns the folder into a proper entry under `projects/`, rebuilds the
site data, and pushes it live.
